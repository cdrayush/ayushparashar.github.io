❓ TROUBLESHOOTING:

Q: Build failed?
A: Run: npm install && npm run build

Q: Can't push to GitHub?
A: Make sure you:
   • Created the repository on GitHub
   • Replaced YOUR-USERNAME in the remote URL
   • The repository name is: username.github.io (lowercase)

Q: Portfolio shows 404 error?
A: • Check if deployment finished (check GitHub Actions)
   • Wait 2-3 minutes and refresh
   • Try incognito/private window

Q: Want a custom domain?
A: See GitHub Pages docs after basic setup works
