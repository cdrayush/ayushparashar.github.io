B) Create repository:
   Repository name: [YOUR-GITHUB-USERNAME].github.io
   Description: (optional - "My interactive portfolio")
   Visibility: PUBLIC ✓
   Click "Create repository"

C) Copy this into terminal (one command at a time):

   cd /Users/ayushparashar/Desktop/portfolio
   
   git remote remove origin
   
   git remote add origin https://github.com/[YOUR-GITHUB-USERNAME]/[YOUR-GITHUB-USERNAME].github.io.git

D) WAIT... the push will upload your code to GitHub
